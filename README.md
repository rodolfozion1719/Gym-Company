# Gym Companion

Projeto pessoal desenvolvido para registrar treinos de academia, contagem de Água e contagem de cárdio (KMs andados)

## Objetivo

Criar um sistema simples para registrar:

- Exercício
- Carga
- Séries
- Repetições
- Data

No futuro o projeto terá:

- Histórico
- Gráficos
- Estatísticas
- IA para análise dos treinos
